# دليل محرر صروح الشرقية

لوحة الإدارة: `https://sorouh-studio.sanity.studio/`.

يمكن تعديل أرقام الاتصال وواتساب، عبارة التوفر، أرقام الثقة، نصوص الصفحات، الخدمات، المناطق، المشاريع وصورها وفيديوهات YouTube، المقالات وفئاتها، الأسئلة الشائعة، وعناوين/أوصاف SEO وصور المشاركة. احفظ المسودة ثم اضغط «نشر» ليظهر التغيير في البناء التالي.

لكل صورة نص بديل عربي إلزامي يصف ما يظهر فعلًا. المقال يحتاج فئة رئيسية، ويمكن ربطه بمدينة فقط عندما يكون المحتوى محليًا. الكاتب يبقى «شركة صروح الشرقية للمقاولات».

داخل SEO اترك canonical المتقدم فارغًا عادةً؛ الموقع يولد self-canonical. لا تفعّل «منع الفهرسة» إلا لصفحة لا تريد ظهورها. عند تغيير slug يسجل النظام المسار السابق تلقائيًا لإعادة التوجيه، ولا يحتاج المحرر إدارة redirect يدويًا.

سجل `content/sorouh/review-register.json` داخلي لمراجعة الاستنتاجات مثل المدينة والتصنيف والمراحل والنتيجة مع العميل، ولا يظهر في الموقع.

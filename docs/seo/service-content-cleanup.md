# تنظيف الخدمات وتحسين الصفحات المحلية

النطاق المعتمد: الدمام والخبر والمنطقة الشرقية، والخدمات التي أكدها العميل. لا يشمل ملف Google Business Profile أو كشف التسربات أو عزل الأسطح. تُحفظ روابط الخدمات القائمة، ومنها رابط قص الخرسانة القديم، مع إزالة ادعاءات الليزر والأرقام وساعات العمل غير المثبتة من النص العام والبيانات المنظمة.

تحسين المحتوى يستهدف ست صفحات في الدمام (دهانات، جبس، سباكة، ترميم، كهرباء، بناء ولياسة) وثلاثًا في الخبر (دهانات، جبس، ترميم). يُربط المحتوى بالصفحة المناسبة للخدمة والمدينة؛ عرض المشاريع يذكر مدينتها الفعلية. لا تُنشأ صفحات متكررة لكل مدينة دون محتوى مستقل.

## تطبيق CMS

```powershell
pnpm cms:service-cleanup --dry-run --output work/service-content-cleanup/review
pnpm cms:service-cleanup --apply --reviewed-plan work/service-content-cleanup/review/review-plan.json
```

الأوامر تستخدم جلسة Sanity الحالية، وتتأكد من المشروع `ki7bs4vk` ومجموعة `production`. لا تضع توكنًا في Git أو سطر الأوامر. يجب قراءة الخطة ومراجعة المعاينة قبل التطبيق. إذا تغيرت مراجعات CMS أو المحتوى بين الخطوة الأولى والثانية يتوقف التطبيق ويتطلب خطة جديدة.

كل تشغيل يحفظ `originals.json` و`review-plan.json` و`preview-documents.json` في مجلد مستقل لا يُكتب فوقه. التطبيق معاملة واحدة مع حراسة مراجعات المستندات. يحتفظ بمسودات استرجاع للصفحات الخمس المسحوبة، ويرفض الكتابة فوق مسودات المحرر أو ترك مراجع قوية إليها. الروابط المسحوبة تعيد 404 وتغيب عن sitemap والروابط العامة.

بعد التطبيق يُتوقع 15 خدمة و14 صفحة محلية و9 مقالات و11 مشروعًا و10 مناطق و5 تصنيفات. ملفات المصدر النظيفة تمنع عودة الخدمات غير المقدمة في نشر محتوى لاحق.

## التحقق والاسترجاع

شغّل `pnpm check` ثم `pnpm verify:production` بعد نشر البناء الجديد. فحص الإنتاج يشمل الصفحات ذات الأولوية والروابط الخمس المسحوبة. يمكن إعادة dry run للتأكد من عدم وجود تغييرات متبقية.

للاسترجاع، احفظ نسخة مستقلة من مجلد التشغيل قبل أي تعديل. الصفحات المسحوبة موجودة كمسودات ويمكن استعادتها من Studio بعد مراجعة مراجعها. الحقول المعدلة أصلها في `originals.json`؛ قارنها مع مراجعات CMS الحالية وأعد الحقول المطلوبة فقط، حتى لا تفقد عمل محرر لاحق. تراجع كود الواجهة بإرجاع commit الإصدار، ثم أعد بناء الإنتاج. تراجع إعداد GTM بإعادة نشر الإصدار السابق من قائمة Versions.

إصلاح الجوال يحجز عرض صورة المقدمة ويمنع تبديل الخط المتأخر؛ فحص محلي مضبوط أظهر اختفاء الانزياح في السيناريو المختبر. هذا لا يمثل نتيجة PageSpeed جديدة أو بيانات Core Web Vitals من المستخدمين الحقيقيين.
